# Neurotrauma CS Lua Addon Annotations
Adds type hints and annotations for NTCS methods, classes and members.

To use this either do:
1. Add to your Lua Addon mod, preferably in a new folder, where all other Lua scripts can see it.
2. Add this to your Lua language server for autocompletion. (Idk how to do this yet)
